## Financial Modelling & Investment Decision Analysis Using Excel

## Project Overview

This project demonstrates the application of Excel-based financial modelling techniques to evaluate investment opportunities, financing decisions, loan structures, and future cash flows. The analysis uses financial functions and modelling concepts including NPV, XNPV, IRR, XIRR, MIRR, PV, RATE, NPER and EMI calculations to assess investment returns, borrowing costs, cash-flow requirements, and financial feasibility.

The project combines structured Excel calculations with financial interpretation and decision-making. Supporting deliverables include an Excel financial model, detailed project report, and presentation.

## Business Problem

Financial decisions often involve evaluating alternative investment opportunities, understanding the cost of borrowing, estimating future cash flows, and determining whether a proposed investment generates adequate returns.

A financial analyst needs to answer questions such as:
* Is an investment financially viable?
* What is the present value of expected future cash flows?
* What return can an investment generate?
* How does the timing of cash flows affect investment value?
* What will be the periodic repayment obligation for a loan?
* How do different interest rates and repayment periods affect financing costs?
* Which financial metrics should be considered before making an investment or financing decision?

This project addresses these questions through structured financial modelling in Microsoft Excel.

## Objectives

The key objectives of the project are to:

* Build an Excel-based financial model for investment and financing analysis.
* Evaluate investment opportunities using discounted cash-flow techniques.
* Calculate NPV and XNPV to determine the present value of investment cash flows.
* Calculate IRR and XIRR to estimate investment return.
* Use MIRR to evaluate investment returns while considering financing and reinvestment assumptions.
* Analyse loan repayment requirements using EMI, PV, RATE and NPER calculations.
* Understand the impact of cash-flow timing on financial valuation.
* Compare investment returns with financing costs.
* Support financial decision-making through quantitative analysis.
* Present the results through a structured report and executive presentation.

## Dataset / Model Overview

Unlike a traditional data-analysis project, this project uses a financial modelling workbook rather than a large transactional dataset.

The Excel model contains financial inputs, assumptions, cash-flow schedules and calculated outputs required for investment appraisal and financing analysis.

## Analysis Performed

**1. Investment Appraisal**

The model evaluates investment opportunities by analysing:

* Initial investment
* Periodic cash inflows
* Periodic cash outflows
* Discount rates
* Investment horizon
* Present value of future cash flows
* Expected investment returns

This provides a structured approach to determining whether an investment generates sufficient financial value.

**2. Net Present Value — NPV**

NPV is used to determine the present value of future cash flows after considering the initial investment.

The analysis helps determine whether an investment creates or destroys value under a specified discount rate.

Key interpretation:

* Positive NPV → investment generates value under the selected assumptions.
* Negative NPV → investment does not recover the required return under the selected assumptions.
* NPV close to zero → investment is approximately at the required return.

**3. XNPV Analysis**

XNPV is used where cash flows occur on specific dates rather than evenly spaced periods.

This provides a more realistic valuation when investment cash flows do not follow a regular annual or monthly schedule.

**4. Internal Rate of Return — IRR**

IRR is used to estimate the discount rate at which the present value of an investment's cash inflows equals its initial investment.

The metric provides a percentage-based view of investment performance.

**5. XIRR Analysis**

XIRR extends IRR analysis to investments where cash flows occur on different dates.

This is particularly useful when actual cash-flow timing varies across periods.

**6. Modified Internal Rate of Return — MIRR**

MIRR addresses some limitations of conventional IRR by incorporating separate financing and reinvestment assumptions.

It provides an alternative return measure when the standard IRR assumption is not appropriate for the financial scenario.

**7. Loan & EMI Analysis**

The model also evaluates borrowing and repayment structures.

The analysis considers:

* Principal amount
* Interest rate
* Loan tenure
* Periodic repayment
* EMI
* Present value
* Number of repayment periods
* Implied financing rate

These calculations help assess the financial impact of borrowing decisions.

**8. PV, RATE & NPER Analysis**

Excel's financial functions are used to solve different financing scenarios.

* PV — Present Value - Determines the current value of future payments or cash flows.
* RATE - Estimates the periodic interest rate associated with a financing arrangement.
* NPER - Determines the number of periods required to repay or accumulate a financial amount based on the relevant assumptions.

## Key Findings / Results

The project demonstrates how different financial metrics can be used together rather than relying on a single indicator. Key observations from the model include:

* Investment feasibility can be evaluated through discounted cash-flow analysis.
* NPV and XNPV provide value-based measures of investment attractiveness.
* IRR and XIRR provide percentage-based measures of expected investment return.
* XIRR/XNPV are particularly useful when cash flows occur on irregular dates.
* MIRR provides an alternative return measure by incorporating financing and reinvestment assumptions.
* EMI analysis helps quantify periodic repayment obligations.
* PV, RATE and NPER can be used to evaluate different loan and financing scenarios.
* Cash-flow timing has a direct effect on investment valuation.
* Financial decisions should consider multiple metrics and assumptions rather than relying on one output.

Note: The numerical results should be interpreted within the assumptions and cash-flow inputs provided in the Excel model.

## Business Insights

**1. Investment decisions should be based on cash-flow economics**
Revenue or profit alone does not determine whether an investment creates value. The timing and magnitude of cash flows are important components of financial valuation.

**2. Cash-flow timing matters**

Two investments can generate similar total cash flows but have different present values because the timing of those cash flows differs.

**3. Multiple return measures provide a broader perspective**

NPV, IRR, XIRR and MIRR answer different financial questions. Using multiple measures provides a more comprehensive assessment of an investment.

**4. Financing costs affect investment decisions**

An investment may appear attractive before considering financing costs. Loan interest, repayment periods and cash requirements should therefore be evaluated alongside expected investment returns.

**5. Scenario-based modelling supports better decisions**

Excel financial models allow analysts to modify assumptions such as interest rates, investment amounts, cash flows and tenure and observe their impact on financial outcomes.

**6. Financial modelling improves decision transparency**

A structured model allows assumptions, calculations and outputs to be traced systematically, making financial analysis easier to review and communicate.

By combining investment appraisal, discounted cash-flow analysis, return calculations, loan and EMI analysis, and financial functions such as NPV, XNPV, IRR, XIRR, MIRR, PV, RATE and NPER, the model provides a structured framework for evaluating financial scenarios.
